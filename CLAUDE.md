# Oriel

A flexible WordPress forms plugin. PHP package `tghp/oriel`, PSR-4 autoloaded from `src/` under the `Oriel\` namespace. Tests run with Pest (`composer test`).

## Agent skills

### Issue tracker

Issues live as GitHub issues in `tghp/oriel`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels, unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
